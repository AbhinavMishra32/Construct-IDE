# Construct 0.8.0

Construct is an IDE that will not write your code for you. It reads your project,
asks you what you think, sets you work, and keeps a map of what you actually
understand. 0.8 is the first release of that idea as a real desktop application:
the app has been rebuilt from the ground up, and almost nothing of 0.7 survives
except the intent.

## The application is new

0.7 was a Tauri shell around a web app. 0.8 is a native Electron application
with a main process that owns the project, the agent, the language servers and
the terminal, and a renderer that is only ever a view of them. That is why this
release is worth downloading even though the version number moved by one digit —
it is not the same program.

- **A real editor.** Monaco with VS Code's own language services: syntax,
  completion, diagnostics, go-to-definition and hover for TypeScript,
  JavaScript, Python, Go, Rust, Java, C++, PHP, Ruby, SQL, HTML, CSS, Markdown,
  YAML, JSON, Docker and shell.
- **A real terminal.** A full pty, not a log pane — your shell, your prompt,
  your tools.
- **A real workspace.** File tree, tabs, split panels, and a command palette,
  laid out so the chat is a peer of the editor rather than a drawer bolted to
  the side of it.

## The agent

Construct's agent runs in its own process, on the Construct prompt, with tools
that are about teaching rather than typing.

- **It reads before it speaks.** A research pass looks at your actual code
  before the first question, so the conversation starts from the project in
  front of you instead of from generalities.
- **It asks, and waits.** Questions arrive as a card in the transcript with real
  choices. A question now survives collapsing the chat, switching projects, and
  quitting the app mid-turn — the app comes back to exactly the question you
  were on.
- **Turns are durable.** A turn is written as it runs and flushed on quit, so
  closing Construct in the middle of an answer no longer loses it.
- **Flow Memory and the path.** What you have been taught, what you struggled
  with, and what comes next are carried between sessions rather than rebuilt
  from the transcript each time.
- **Practice tasks.** The agent can set you work, watch you attempt it, and
  evaluate the attempt against what it was actually testing.

## What you know, drawn

Concepts are no longer a list. The atlas is a map of your understanding across
every project: a force-directed web and an orbital view, coloured by cluster,
with zoom, focus and momentum. Each concept opens into real written content in a
sidecar beside your code — not a modal over it — and anything you no longer want
recorded can be forgotten outright.

## The new look

This is the release where Construct stopped looking like a prototype.

- **The transcript is a thread.** Every step the agent takes hangs off a single
  line running down the icon column, and that line grows and closes with the
  step it belongs to instead of being drawn in segments beside it.
- **Steps read as sentences.** "Asked a question", not "Prepared a question" —
  each row is named for what you watched happen, in one weight of grey, going
  dark only under the cursor.
- **Questions and answers, legibly.** An answered question shows the question
  and your answer, not the tool's JSON.
- **Thinking orbs everywhere.** Every place the app is working now says so with
  a hand-tuned orb — searching, solving, connecting, weaving, listening,
  shaping — instead of a spinner. Settled thoughts slide into place from the
  orb's gutter rather than snapping.
- **One surface per panel.** The blue band is gone, the glass is gone, the gaps
  are tighter and the shadows deeper. The top bar is Construct's own.

## Fixes worth naming

- Tool calls are routed to the project they belong to, so two open projects no
  longer bleed into each other's transcripts.
- The shell survives a renderer crash instead of taking the window with it.
- Sign-in presents the session as a cookie, which is what the API actually
  authenticates.
- Making a project asks for nothing but a name: there is a projects folder, and
  it is remembered.
- Step text is no longer parsed on the assumption that every tool returns a
  string.

## Installing

- **macOS** — `Construct-0.8.0-arm64.dmg` for Apple Silicon,
  `Construct-0.8.0.dmg` for Intel.
- **Windows** — `Construct-0.8.0-x64.exe`.
- **Linux** — `Construct-0.8.0-x64.AppImage` or `Construct-0.8.0-x64.deb`.

Construct updates itself from here on: this release ships the update feed the
app polls, so 0.8.1 will arrive on its own.

These builds are not code-signed. macOS will ask you to approve Construct the
first time (Right click → Open, or System Settings → Privacy & Security →
Open Anyway), and Windows SmartScreen will ask for the same. Signing certificates
are configured through repository secrets, and the moment they exist these same
builds are signed and notarized with no other change.

## Known gaps

- Deleting your account from Settings does not work yet — the endpoint is not
  live on the API.
- Linux and Windows builds are x64 only; there are no arm64 packages for either.
